## Revisions

- **v1.5** (`amyboard-v1.5.sch` / `.brd`, from Makerfabs) — same CV/audio circuits as
  v1.4; the negative-rail regulator changed to an SGM2209-ADJ (still -12V). Note the
  GP8413 DACs on the v1.5 production run are a newer date-code batch that powers up in
  a half-scale output range — see the
  [CV troubleshooting entry](../../amyboard/troubleshooting.md#cv-out-voltages-are-wrong-v15-boards).
- **v1.4** — first production revision (`amyboard-v1.4.sch` / `.brd`, PNG above).
- **v1.0 / v1.1dpwe** — prototypes.
